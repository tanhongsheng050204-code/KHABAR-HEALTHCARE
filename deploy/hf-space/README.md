# Khabar backend

The Java API and the Python agents of [Khabar](https://github.com/tanhongsheng050204-code/KHABAR-HEALTHCARE),
a clinic follow-up prototype. **Fictional data only.** The web app is at https://khabar-landing-six.vercel.app.

Settings (Space → Settings → Variables and secrets): `DATABASE_URL`, `INTERNAL_SERVICE_KEY`, `SUPABASE_JWT_SECRET`,
`SUPABASE_JWKS_URL`, `FIELD_ENCRYPTION_KEY`, `WEB_ALLOWED_ORIGINS`, `WEB_APP_URL`, `NEO4J_URI`, `NEO4J_USERNAME`,
`NEO4J_PASSWORD`, and optionally `GEMINI_API_KEY`, `GROQ_API_KEY`, `KHABAR_TELEGRAM_BOT_TOKEN`,
`KHABAR_TELEGRAM_WEBHOOK_SECRET`.
