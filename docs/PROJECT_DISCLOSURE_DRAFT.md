## Draft disclosure text

> Our project builds on a pre-existing generic starter template, which we will disclose separately and use only subject to organiser approval. The project code integrates Supabase (authentication and PostgreSQL), Vercel (web/API hosting), Neo4j AuraDB (de-identified graph storage), Gemini (optional language-model tasks and medicine-packet label reading), Groq Whisper (optional speech-to-text), Meta WhatsApp Cloud API (message integration), and Favoriot (home-reading webhook integration). It includes a reproducible, attributed subset of DDInter 2.0 interaction data under CC BY-NC-SA 4.0. Provider integrations are at different stages: some are code-only or simulated and must not be described as live or evaluated unless a real-provider test was completed. AI coding assistance was used; the exact products, versions, dates, and extent of assistance must be confirmed by the project owner. All patient examples and rehearsal records are fictional.
